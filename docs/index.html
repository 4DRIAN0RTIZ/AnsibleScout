Installation

Using curl

curl -fsSL https://raw.githubusercontent.com/4DRIAN0RTIZ/AnsibleScout/main/install.sh | bash

Or using wget

wget -qO- https://raw.githubusercontent.com/4DRIAN0RTIZ/AnsibleScout/main/install.sh | bash

Configuration (Optional)

Create ~/.config/ascout/config.toml for AI features:

[ui]
theme = "dracula"

[ai]
enabled = true
model = "gpt-4o-mini"
api_key = "sk-your-openai-key"

[ansible]
modules_file = "/tmp/ansible_modules.json"

Basic Mode

ascout

Examples

AI Semantic Search

  1. Type "backup database" in the search box
  2. Press Ctrl + I to activate AI semantic search
  3. AI finds semantically related modules: mysql_db, postgresql_db, archive
  4. View AI recommendations and select the best module for your use case

Search for file copying modules

  1. Type "copy files" in the search box
  2. Press 1 to jump to the first result
  3. Use j / k to browse other results
  4. Press Enter or d to view details

Quick navigation

  1. Type your search query
  2. Press g to jump to top result
  3. Press G to jump to bottom result
  4. Press 3 to jump directly to third result
